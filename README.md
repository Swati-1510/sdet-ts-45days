# 45-Day SDET & QA Automation Journey (TypeScript)

A structured, hands-on engineering log building production-ready QA & SDET skills in **TypeScript**—covering algorithmic problem solving, SQL validation, API & contract testing, modern Playwright automation, AI-assisted testing workflows, and CI/CD pipelines.

## Tech Stack
- **Language:** TypeScript (Node.js)
- **UI & API Automation:** Playwright, Zod (Schema/Contract Validation)
- **AI Testing Workflows:** Playwright Test Agents & MCP, Promptfoo
- **Performance & CI/CD:** Grafana k6, Docker, GitHub Actions
- **Database:** SQL (PostgreSQL / MySQL)
